# Mental Health & Social Media Database

A relational database designed from scratch analyzing the relationship 
between social media usage and mental health indicators.

## Overview
This project covers the full database design lifecycle. From 
conceptual, logical, and physical diagrams to schema creation, 
data population, and SQL queries. The database tracks social media 
usage patterns alongside mental health states including mood, 
anxiety, and general mental health indicators.

## Database Tool
MySQL

## Design Process
1. Conceptual diagram — identified entities and relationships
2. Logical diagram — defined attributes and keys
3. Physical diagram — finalized data types and constraints
4. DDL— created tables in MySQL
6. Data migration (DML) — extracted and loaded raw dataset into 
   normalized tables via ID mapping and JOIN operations
7. Queries — wrote SQL queries for analysis

## Key Entities
- Social media usage patterns
- Mental health states (mood, anxiety)
